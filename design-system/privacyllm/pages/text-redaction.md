# Text Redaction Workspace Override

This page overrides the automatically suggested dark violet marketing palette
because the product is a trust-first local privacy utility, not an AI SaaS
landing page.

## Direction

- True light cool-gray background (`#f5f7f8`) and white work surfaces.
- Deep charcoal text (`#17212b`), slate secondary text (`#53626f`).
- One teal accent (`#087f78`) for active navigation, focus, and primary actions.
- Error `#b42318`, warning `#a15c00`, blue project highlight `#2869a7`.
- System Chinese sans-serif stack; no external font requests.
- 4/8px spacing rhythm, 8px controls, 12px structural panels.
- Editor/list layout at desktop; strict single-column below 960px.
- Motion limited to 150-200ms interaction feedback and state transitions.

## Component Model

- Header: 64-68px, text-first brand, local-only status, four tabs.
- Workspace: 3:2 editor and review columns, open sections with thin borders.
- Review entities: compact rows, not decorative cards.
- Inputs: labels above fields, persistent helper/error text.
- Focus: 3px teal focus ring with offset.
- States: loading skeleton, empty output, inline error, disabled semantic mode.

## Prohibited

- Purple, gradients, glow, glass, dark theme, external assets, decorative
  status dots, shield illustrations, fake metrics, version strings, clocks,
  autosave claims, cloud terminology, marketing hero content.
